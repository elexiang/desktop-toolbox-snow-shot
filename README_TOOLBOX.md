# Snow 工具箱 0.2.1

基于 Snow Shot 1.5.7（`6a9c162f56e73a95190015c5825440106a114c0f`）的 Windows x64 个人工具箱，保留上游 Qt/C++ 与 Rust 架构。新增代码采用 GPL-3.0-or-later。开发分支为 `codex/snow-shot`。

完整解压后双击 **SnowToolbox.exe**。关闭面板只隐藏；退出请使用面板、额度卡片右键或托盘中的“退出工具箱”。首次打开显示面板，之后保留桌面额度卡片和托盘。

- 默认 **Ctrl+Alt+1** 框选截图，然后选择标注、识字、翻译、复制、保存或原位贴图。快捷键冲突会提示，可在设置修改。
- 截图中 **C** 复制 RGB，**X** 复制 HEX，保留当前选区；**Ctrl+O / Ctrl+T / Ctrl+P / Ctrl+C / Ctrl+S** 分别识字、原图翻译、贴图、复制图片、保存。文字标注输入时优先正常编辑。
- OCR 弹出原文/译文面板并自动中英互译。直接点击“翻译”则将译文排入冻结截图区域。翻译不调用在线服务，专业术语和长句请核对。
- 桌面卡片可拖动，显示短时/每周真实额度及重置时间；悬停查看详细额度、内存和两个清理按钮，点击卡片打开主面板。
- 0.2.1：额度卡压缩为单行，例如 `5h 82% ⟳15:16　w 37% ⟳11-18 16:09`，⟳ 表示重置时间。当天 5h 窗口省略日期，跨日保留月日；过期用灰色数值与 `!` 标记，完整状态仍在悬停详情中。RGB 放大镜仅在确认选区前显示，确认后、调整选区和标注期间隐藏；C/X 复制颜色继续可用。
- 额度使用本机已经登录的 Codex CLI。可在设置指定 `codex.exe`；无需启动 Codex 桌面端。查询完成后回收自有查询进程，默认每 60 秒刷新，失败保留旧值并标记过期。无有效数据时显示 `--`。
- OCR 按需启动并用后释放；翻译进程闲置 60 秒后退出。所有功能可以分别启停。
- 设置中的 **启用 1M 上下文** 沿用个人 CC GUI 行为：开启设置上下文 `1000000`、压缩阈值 `900000`；关闭删除两项覆盖，恢复模型默认。修改 `%CODEX_HOME%/config.toml`（未指定时为用户目录 `.codex/config.toml`），修改前自动备份，保留其余内容。若当前选定配置档也有这两项覆盖，会一并移除，使其继承全局设置；其他配置档不变。需要重新启动 Codex 会话并且模型本身支持；项目配置、命令行参数仍可覆盖用户级设置。此开关独立于额度查询，无常驻辅助进程。
- 常规清理保护工具箱、前台应用、系统进程、IDEA、Codex、Java/Node 及其子进程。深度清理通过一次性管理员辅助进程整理系统工作集、修改页、待机列表及文件缓存，可能影响全系统缓存；取消授权不会显示为成功。不自动清理，不修改分页文件，不结束应用。
- 贴图沿用 Snow Shot 的拖动、缩放、透明度、复制、保存和穿透等操作；“恢复贴图”用于找回隐藏的贴图并取消穿透。

模块设置位于 `%LOCALAPPDATA%\SnowToolbox\toolbox.ini`；截图与贴图数据由 Snow Toolbox 独立的 Snow Shot 配置目录管理，不修改旧 Qt 工具箱或原版 Snow Shot 配置。内存应测主程序及全部自有子进程；不以清空工作集后的瞬时数值承诺省内存。

源码构建需要 MSVC 14.51+、Rust 1.97.1、CMake 4.2+、Qt 6.12.0 和固定版本 vcpkg 依赖。可使用 `scripts/build-toolbox.ps1` 构建动态 Qt Release；`scripts/package-toolbox.ps1` 部署便携目录。可通过 `-OcrExecutable` 复用已校验的官方 OCR 工作程序，并同时提供完整 `assets/ocr` 资源。源码、版本和授权信息随交付包提供。

完整包无需预装 Qt、Rust 或 Python。此版本未购买代码签名证书；具体已通过项目和多屏/DPI等未验证项目，以交付验收说明为准。
